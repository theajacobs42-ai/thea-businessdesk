IMPORTANT ABOUT THE ENQUIRY FORM:
This first version does NOT silently send or store enquiries. When a visitor submits the form, it opens their email application with a message addressed to theajacobs42@gmail.com. The visitor must press Send. This avoids a paid form service, but it is not equivalent to a hosted form backend and depends on the visitor having an email app configured.

DEPLOYMENT:
This is a standalone static website package. It has not been published and does not modify the existing AI-BusinessDesk Worker, D1 database, or application. Before public launch, upload these files to a NEW, separate Cloudflare Pages project. Do not change the existing Worker project.

No paid services are included in this package.
